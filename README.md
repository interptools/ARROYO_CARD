# Arroyo Suite — digital calling card

NFC / QR landing page for Reymar Arroyo. Static, no build step, no dependencies to install.

## Files

| File | Purpose |
|---|---|
| `index.html` | The card itself. All styles and scripts are inline. |
| `contact.vcf` | Static vCard fallback for browsers that block Blob downloads. |
| `.nojekyll` | Stops GitHub Pages from running Jekyll. Leave it in place. |

## Publish on GitHub Pages

1. Create a repository named `card` under your account.
2. Upload all files in this folder to the repository root — not inside a subfolder.
3. Go to **Settings → Pages**.
4. Under **Source**, choose `Deploy from a branch`.
5. Set branch to `main` and folder to `/ (root)`. Save.
6. Wait about a minute. The card is live at:

   ```
   https://interptools.github.io/card/
   ```

If you use a different repository name, replace `card` in the URL and update the two places noted below.

## After the first deploy

Two values reference the live URL and should match it:

- `index.html` — the `og:image` meta tag near the top
- `contact.vcf` — the `URL:` line

The in-page vCard generated by JavaScript reads the real URL automatically, so it needs no edit.

## Write the URL to an NFC tag

Tags: NTAG213 or higher. NTAG213's 144 bytes is plenty for this URL.

**Android**

1. Install *NFC Tools* by Wakdev.
2. **Write → Add a record → URL/URI**.
3. Paste `https://interptools.github.io/card/`.
4. Tap **Write**, hold the tag against the back of the phone.

**iPhone 7 and later**

Same flow using the iOS build of *NFC Tools*. Hold the tag near the top edge of the phone, close to the camera.

**Lock the tag** once tested: *NFC Tools → Other → Set read-only*. This is permanent and stops anyone rewriting your card to point elsewhere. Keep one tag unlocked as a spare.

## Updating your details

Edit `index.html` and `contact.vcf`, then commit. Every tag already handed out picks up the change immediately, because the tag stores only the URL.

## Optional additions

Commented-out blocks are not included, so to add a link just copy an existing `.row` anchor in the **Get in touch** section and change the `href`, label, and glyph. Candidates worth adding later:

- LinkedIn profile
- LINE ID — widely used by Japanese clients
- Booking link for interpretation slots
- Rate card or portfolio PDF
